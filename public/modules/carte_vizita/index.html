How to print or save as PDF:

  1. Click the **Print Cards / Save PDF** button above (or press **Ctrl + P**).
  2. In the print preview window, change the **Destination** to **Save as PDF** or select your printer.
  3. Set **Layout** to **Landscape**.
  4. Set **Paper size** to **A4** (or standard card stock size if printing directly).
  5. Set **Margins** to **None** to ensure the cards print at exactly 85mm x 55mm.
  6. **IMPORTANT:** Under *More settings*, ensure **Background graphics** is checked, otherwise the logo elements will not render correctly.
  7. Click **Save** or **Print**. (The printer will automatically output 4 individual pages - 2 for the Romanian card and 2 for the English card, ready for double-sided cutting).
